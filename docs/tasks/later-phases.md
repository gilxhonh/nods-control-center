# Phases 5 to 12 (epics)

Break each epic into NCC tasks when the phase starts.

- **5. Tickets:** Jira sync into ticket_snapshots; link tickets to domain/run/store; root-cause taxonomy; Tickets page with filters; Weekly report (requests on time vs with ticket, root causes, client summary); Slack activity on Domain detail.
- **6. Writes:** Baseline change flow (whole domain or specific stores, required ticket, two-step confirm, request flow for engineers); assignments and reassignment with handover note; activity timelines from audit_log.
- **7. Blocks and proxies:** domain_blocks lifecycle (open, update ETA, resolve), blocked banners for CSMs; proxy usage ingestion per provider, pools, cost per 1K records.
- **8. NODS parity:** Weekly Requests (week picker, config changes, input changes), Store Coverage (low counts, missing stores).
- **9. Role views:** Team page and member drawer, CSM client impact summary, segment separation review and tests.
- **10. Alerts, analytics, explorer:** alerts table + rules, acknowledge, Slack DM delivery; Analytics charts; Data Explorer with saved read-only queries; Integrations health from sync_runs.
- **11. Launch:** SSO (OIDC), hosting, secrets management, backups, monitoring (Prometheus/Grafana, Sentry), runbook, retire NODS read paths.
- **12. Later:** create Jira tickets from templates (needs write approval), MCP server over Nods Control Center data, Node 26 upgrade.
